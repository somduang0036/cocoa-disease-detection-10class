# Dataset Downloads

Download the archives from the Cocoa Disease Detection Dataset on Hugging Face.
(https://huggingface.co/datasets/tassanee/cocoa-disease-detection-10class/tree/main)

1. Extract images.rar so that the images are under dataset/images/.
2. Extract labels.rar so that the labels are under dataset/labels/ for standalone YOLO use.

Model 1: dataset/model1_metadata.csv provides the image-level labels for Cocoa and Other Plants.

Model 2: Keep dataset/model2_train_val_labels.zip in ZIP format for training. The held-out test uses dataset/matadata_model 2/annotations_test.coco.json.
